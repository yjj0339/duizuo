# DUIZUO 3.4.0 · 移动端布局重做

发布日期：2026-10-26。页面版本标记：`mobile-v9`。

本版修复手机横屏拦截、反向横屏遮挡和过多场外控件。32 款共用简洁的返回、菜单、比分与事件提示；棋盘、体育、动作、益智四组分别适配布局。

## 游玩变化

- 横竖屏均可直接游玩，不调用全屏或屏幕方向锁定。旋转设备保留当前对局，不发送暂离状态。打开菜单、切后台、断线仍按原保护机制暂停。
- 羽毛球：一个左右摇杆、击球、起跳。自动判断合法球路；手动球路、落点与画质在「菜单 → 球场设置」。乒乓球为移动摇杆、回击、挑高；键盘 3 保留快攻。台球为拖动瞄准、力度、击球，杆法在设置中。
- 停步用服务端 `stop` 动作清除目标距离与速度，避免使用滞后快照导致松手后漂移或回走。菜单打开会清除持有输入，恢复后先处理待执行停步。
- 立体相机按实际宽高与 HUD / 拇指区留白进行取景，指针仍经同一个相机反投影。左右安全区、底部手势区、可视视口高度分别处理。
- 海战布阵在横屏拆成棋盘与工具两列；战斗时缩小己方防守图。翻牌横屏六列、竖屏四列，键盘选格随列数变化。数独和方块横屏使用侧边操作；动作游戏的按钮纳入场地外框，画布保持原始比例。
- 「技巧与观察」进入菜单，使用真实控件节点往返挂载并保留事件、状态；练习换人、撤销、AI 分析仍有菜单入口。

## 验证证据

- `runtime/logs/test-mobile-v9.txt`：320 项单元 / 引擎 / 网络测试通过。
- `artifacts/mobile-v9/final-audit/report.json`：32 款 × 4 种手机布局，共 128 张快照，无横向溢出；三款立体体育场景的按钮均在可用视口内。
- `artifacts/mobile-v9/experience/experience-report.json`：129 项实际操作、反馈、暂停、清理、窄屏与减少动态效果检查通过。
- `artifacts/mobile-v9/navigation/report.json`：45 项菜单层级、返回、存档、更新、双通道恢复检查通过。
- `artifacts/mobile-v9/controls/report.json`：8 组检查覆盖 320×568、390×844、568×320、844×390、左右刘海、底部手势区、双指移动击球、松手停步、设置保留与输入法视口变化。
- `artifacts/mobile-v9/dimension/report.json`：16 项模型加载、触控投影、设置暂停、资源释放、图形上下文恢复检查通过。
- `artifacts/mobile-v9/online/report.json`：Socket.IO 与 HTTPS 两个独立客户端，6 组对战、旋转、设置暂停、延迟暂离消息恢复检查通过。
- `artifacts/dimension-v8/mobile-v9/profile.json`：本机 Chromium 的六组 8 秒渲染样本，实际模型渲染约 59–60 FPS。此为本机模拟视口结果，不代表所有实体手机性能。

这些报告属于本地验收产物，不包含在网站构建里。实体 iPhone / Android、不同系统浏览器工具栏和网络条件仍需真实设备反馈；没有宣称所有手机均已实测。

## 发布与恢复

源码与数据库备份位于 `runtime/backups/mobile-v9-before/`，SQLite 备份通过完整性检查，保留 166 条已有战绩。升级前确认服务无活动房间。已有单人存档格式和服务端对局格式保持兼容。

远程对战仍需要 D 盘本地服务及公网隧道在线。发现旧临时隧道已被服务商移除，发布时重新验证入口后更新地址登记；临时隧道不等同于永久服务器。前端继续支持从登记地址发现新入口与恢复身份。
