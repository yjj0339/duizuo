## 使用范围

规则模拟不等同于人类对战胜率。棋类和益智 AI 采用各自算法，体育 AI 使用几何与球路预测。没有无敌或零缺陷承诺。

浏览器验证使用同一台电脑的独立桌面 / 手机视口上下文；这不等同于不同城市真实手机、蜂窝网络、系统强制结束后台的实测。页面关闭后能通过保留身份与重同步恢复，不能要求操作系统始终维持后台网络。

GitHub Pages 托管前端；在线对战依赖 D 盘本地服务、电脑常开和当前公网隧道。临时隧道仍有地址和入口可用性限制，关机后不能远程对战。完整提示词见《制作提示词》。
