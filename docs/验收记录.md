## 实现范围

20 款独立游戏全部具有规则、渲染器、触摸/鼠标或键盘输入、服务端判定与结束状态。支持双人房间、六位房间码、带服务器地址的邀请链接、双方准备、3 秒同步倒计时、结算、再来一局、更换游戏、3/5 场巡回赛、表情、音效开关、本机战绩和身份重连。

## 公网浏览器验证

桌面浏览器与 390px 触摸浏览器通过实际 GitHub Pages 页面和公网入口逐款验证。**20 款全部完成，共 61 项检查通过，0 浏览器异常。** 每款检查真实界面操作经公网服务器接受、手机伙伴收到状态且无横向溢出、双方到达结算；另检查刷新后保持原玩家身份和进行中的对局。最终明细见本机 `artifacts/online-verification.json`。这些检查包含以认输结束的对局；完整规则结束另外由规则测试与 20 款对局模拟覆盖，没有将其描述成 20 场人工完整比赛。

## 部署说明与验证边界

当前 GitHub 授权没有 `workflow` 范围，因此采用已验证可用的发布分支方式。`scripts/publish.ps1` 提供测试、构建和分支发布；完整 Actions 模板保存于 `docs/pages-workflow-template.yml`，未声称该模板当前已经在运行。

公网对战服务在本机运行，需保持开机联网。当前使用临时公网隧道，启动器会同步变更后的地址；没有固定域名或持续可用性保证。要长期固定地址，可另行接入自有域名的命名隧道或独立云主机。

浏览器验证由同一电脑上的两个独立浏览器上下文完成，其中一个使用手机尺寸和触摸能力；没有把它表述为真实异地手机/蜂窝网络测试。后端重启会清空正在进行的内存房间，SQLite 保留已经结束的对战。没有对所有操作系统、浏览器引擎和高延迟条件作兼容性或公平性保证；反应力游戏会提示网络延迟影响。
