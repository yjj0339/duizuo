# 对座 3.1 · 进得去，也回得来

发布日期：2026-10-23。客户端与服务端版本 3.1.0，发布标识 navigation-v6，游戏数量保持 32 款。

## 本次改进

- 每个游戏顶部常驻“返回 / 游戏名称 / 菜单”。手机触控按钮至少 44 像素；放大场地后仍可返回。
- 菜单提供继续、玩法、声音、放大、版本、返回；单人可重开，联机可复制邀请与确认认输。玩法、重开确认支持回到上一级，Esc 与浏览器返回按层退出。
- 单人及同屏进度按游戏分别保存，兼容旧存档。同屏操控席位也保存。各游戏入口显示“继续上次”，重开前确认替换该游戏进度。
- 返回游乐场恢复原来的列表位置与焦点；顶部提供继续上次 / 继续联机 / 查看结果入口。
- 联机回房间进入暂离保护，暂停双方计时与模拟，最多 180 秒。网络重连、焦点切换和服务器快照不会强制切回场地。继续后双方倒计时恢复原局。
- 修复暂停时无法确认认输，以及高频房间快照可能连续触发浏览器后退而退出页面的问题。认输仍由服务器校验身份、序号并只结算一次。
- 菜单和规则页暂停单人模拟、AI 与动画，隔离键盘输入；关闭时只释放菜单本身取得的暂停。
- 版本页显示当前改进并支持检查更新。单人保存后更新；进行中的联机局不会被更新按钮打断。
- 旧临时公网入口失效时，尝试读取已发布入口并做健康验证，再恢复连接。自定义非临时服务器地址不会被此逻辑替换。

## 验收

自动化脚本使用 D 盘 Node、Chromium 与临时目录。网页端实测与服务器规则测试分开记录：

- `node --test tests/*.test.js`：279 项通过。
- `scripts/verify-navigation-v6.mjs`：32 款菜单、分层返回、独立存档、刷新继续；浏览器后退、键盘、重开取消；320×740、390×844、844×390、1440×980 布局；Socket.IO / HTTPS 双端暂离、重连、继续、确认认输与下一局。45 组通过。
- `scripts/verify-experience-v5.mjs`，输出至 `artifacts/navigation-v6/game-regression`：129 项动作、暂停、动画清理及响应式回归通过。
- 全 32 款双端联机回归：109 项通过。公网发布验证见 `artifacts/navigation-v6` 的报告。

这些检查使用桌面 Chromium 和手机尺寸模拟，不等于已经在所有手机、系统和弱网环境逐台验证。服务器与公网隧道仍依赖本机开机联网；房间保护不等于永久在线。存档保存在当前浏览器，清除浏览器数据会删除本地进度。
