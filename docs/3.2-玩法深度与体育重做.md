# 对座 3.2 · 每一拍，都有讲究

2026-10-24 / 客户端与服务端 3.2.0 / gameplay-v7 / 32 款游戏。

本轮重点是羽毛球、乒乓球、台球的规则与动作一致性，以及方块对战的策略空间。32 款全部增加针对各自局势的观察、训练目标和三段进阶手册。没有把新增手册等同于 32 款核心玩法全部重写。

## 羽毛球

- 权威引擎和界面、AI 共用触球规则；击球区域为有限椭圆，不能隔网或远距离击球。
- 起跳有完整 650 ms 上升、顶点、落地过程，起跳瞬间不会直接获得最高触球高度。扣杀要求高点击球。
- 近网、中场、后场落点决定实际落地位置；高远、吊球、扣杀采用不同飞行时间，按重力和水平阻力解算过网弧线。
- 甜点击球影响球的飞行时间。脚步有加速度，冲刺与起跳消耗体力并自动恢复。
- 挥拍时球拍对齐实际接触点；有跑动、跳跃、冲刺残影、羽球尾迹、落点提示、体力条与回合拍数。
- 每一分记录落地、触网或出界等原因和拍数。最长回合、甜点次数来自真实事件。
- AI 预测公开轨迹选择接球位置，并根据对手站位选择远近落点。不同难度有不同反应、跑位和球路，不读取隐藏信息。

## 乒乓球

- 发球先在己方台面弹跳，再越网落入对方台面。接发必须经过一次己方弹台，不能抢打、连击。
- 上旋前冲、下旋减速，旋转还影响落台后的弹跳高度；低来球不能快攻。
- 发球轻擦网重发，其他触网、落界外、二次弹台与漏接均有明确判分。
- 双方球员、手臂和球拍随移动和挥拍表现，弹台位置单独生成事件，球影与球的高度分离。
- 仍是 11 分净胜 2、15 分封顶的休闲快局，保留每两分换发、10 平后每分换发，并非完整比赛模拟器。

## 台球与方块

- 台球增加拉杆／顺杆，首撞后白球会回退或继续前进；滑块显示中杆和杆法强度。
- 补齐“触球后必须有球碰库或进袋”的犯规判定，保留错球、空杆、白球落袋、提前黑八和自由球。上一杆原因进入战术观察。
- 仍为简化八球，未实现完整开球、指袋、跳球和曲线杆规则。
- 方块对战增加 C／触控暂存，当前块只能换一次，锁定后恢复；连消加分并增加攻击，先抵消己方待接收障碍再进攻。

## 稳定性与兼容

旧存档缺少新增字段时按需初始化，不删除存档。修复暂停恢复后的跳跃时间映射；菜单暂停时清空体育移动按键，防止回来后继续误移动。滑块显式关联可访问名称，键盘可调节。新增手册中的按键不会传给场内。

服务端依旧负责所有得分、接触、碰撞和胜负。3 分钟暂离保护、Socket.IO 与 HTTPS 备用连接、分层返回、菜单及按游戏存档继续保留。临时隧道和本地服务器仍需电脑开机联网。
