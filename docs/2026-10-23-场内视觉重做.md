# 场内视觉与动画重做

目标：32 款游戏的场内信息清楚、操作顺手；体育游戏达到有完整动作表现的轻量运动游戏观感。保持现有权威规则、AI、存档和双通道联机。

视觉方向：浅雾白 #f5f8fb、深蓝灰 #29454b、球场绿 #298c79、蜜桃 #eb7969、薄荷 #35ad93、暖木 #bc8452。中文沿用系统苹方/微软雅黑；比分使用等宽数字。信息层级为比分与回合、场地、主要操作、可展开规则，压缩重复说明和手机头部。

最有辨识度的内容放在实际场地：台球的木框、绒面、袋口深度、球体反光与旋转；羽毛球的球馆、分节人物跑跳挥拍、球拍网面和羽球。使用可缩放程序绘图，不引入会丢失的远程贴图。

动作层独立于规则：快照插值、持续渲染、击球后摆、球轨迹、入袋/弹台/进球反馈；保持命中、计分由现有游戏引擎决定。所有循环与监听退出时清理，暂停冻结，减少动态效果时保留必要球路。

范围：重做六款体育渲染；32 款共用的紧凑比赛界面、专注模式、对局信息与控件层级；棋盘与益智的材质及落子/翻转/滑动反馈。

验收：逐款桌面与手机截图、32 款控件回归、连续动作帧差、移动/挥拍/进球过程视频、暂停/退出清理、减少动态效果、正式页面发布核对。测试结果只证明已覆盖场景，不能代替所有真实设备体验。

## 已完成验收

- Node 测试：222 项通过。新增视觉插值不修改权威状态、起跳弧线及击球提示和实际判定一致性验证。
- 32 款 × 1440 / 390 / 320 像素：96 次界面检查，无横向溢出或缺失 SVG。
- 动态画面、暂停冻结、专注模式退出及减少动态效果合计：105 项检查通过，见 `artifacts/visual-v4/report.json`。
- 六款体育游戏均通过实际控件操作；台球滚动、羽毛球与乒乓球连续回合、箭矢、点球揭晓和跳吃棋动画已录制。退出每款后，动画循环数恢复到大厅基线，见 `artifacts/visual-v4/motion-report.json`。
- 32 款双浏览器联机回归：109 项通过，均能接受操作并在双端结算，见 `artifacts/visual-v4/online-report.json`。
- 修正了球拍网格绘制后边框路径丢失、右侧球衣文字镜像、球台纹理过重及横屏画布留白导致的触点坐标问题。
- 全部资源、缓存、运行时、录像及临时文件保存在 D 盘。画面采用本地程序绘图，动画独立于服务器规则。

截图和录屏是本机 Chromium 的结果。双浏览器模拟手机视口不等同于所有实体手机；帧数记录用于确认循环持续与退出清理，不作为跨设备帧率保证。
