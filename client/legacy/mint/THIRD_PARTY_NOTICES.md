# AI evaluation attribution

The polynomial row evaluation and weights in `ai.js` and `native/solver.c` are adapted from Robert Xiao's [2048-ai](https://github.com/nneonneo/2048-ai), specifically `2048.cpp`. The JavaScript and C/WebAssembly searches, five-bit row representation, variable board sizes, fixed-size verified caches, time budgeting and UI integration are local adaptations. The compiled `solver.wasm` retains this attribution through this accompanying notice.
