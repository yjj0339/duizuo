# DUO PLAY 双人游乐场：完整制作提示词

请设计、开发并交付一个可通过 GitHub Pages 直接打开的中文双人在线对战小游戏合集，名称为「DUO PLAY · 双人游乐场」。总共 20 款真实可玩的游戏，适合情侣和朋友；手机竖屏和桌面浏览器均可操作。

## 20 款游戏与验收规则

1. 五子棋：15×15 自由规则，轮流落子，五连获胜，满盘和棋。参考 D:/codexAI/aurora-gomoku 的玩法和手机体验。
2. 隐藏海战：双方独立布阵，可重新随机布阵；准备后轮流轰炸，服务端隐藏未命中的舰船位置，先击沉全部敌舰获胜。
3. 点格夺地：连接相邻圆点，封闭格子获得领地并继续行动，格子多者获胜。
4. 翻牌记忆：轮流翻牌，配对得分并继续翻；未翻开的牌面不得发给客户端。
5. 迷你冰球：拖动球拍防守和射门，服务器计算运动与碰撞，先得 7 分获胜。
6. 口袋坦克：移动、瞄准、射击，障碍阻挡炮弹，血量耗尽落败。
7. 泡泡炸弹人：格子地图、可炸砖块、放置炸弹、十字爆炸、判定胜负，提供触摸方向与动作键。
8. 贪吃蛇竞技场：同步移动、吃食物增长、身体和墙壁碰撞判负，支持同时碰撞和棋。
9. 方块攻防战：同一随机种子的方块序列，服务器校验移动、旋转与落地，消行发送障碍行，对手封顶获胜。
10. 弹弓城堡：轮流调整角度与力度，服务器计算抛物线、风力与命中，摧毁对方城堡获胜。
11. 迷宫夺旗：对称可达地图，抢旗并带回出生点，支持移动端方向键。
12. 趣味知识擂台：内置审校题库，同题作答，正确得分，限时自动进入下一题，最终比较总分。
13. 2048 对决：参考 D:/codexAI/mint-1024/engine.js 的合并规则；统一命名为 2048，同种子开局、限时比拼分数，支持滑动和方向键。
14. 数独竞速：参考 D:/codexAI/sudoku-atelier 的数独规则；相同唯一解题目，校验填数，比较完成度及正确性，提供数字键盘。
15. 黑白棋：合法夹击翻转、无棋可下自动跳过、双方均无合法落子时结算数量。
16. 石头剪刀布：双方暗选，齐选后揭晓，先得 3 分获胜，平局重赛。
17. 反应力对决：随机等待后出现信号，抢跑有惩罚，多轮比赛；提示网络延迟会影响结果。
18. 扫雷竞速：同种子地图，开格、插旗、空白区域展开，踩雷扣分，完成安全格或时间到结算。
19. 打字竞速：同一中文句子，按输入进度与正确完成情况比赛，支持中文输入法。
20. 节奏记忆：依次展示音符/颜色序列，双方按序复现，逐轮增长，按正确输入和轮次得分。

## 产品体验

- 默认浅色毛玻璃设计：云白底、蜜桃粉和薄荷绿玩家配色，游戏卡片有定制图形；大厅、房间、游戏、结算有完整状态。
- 昵称进入，无需注册。创建双人房间，用房间码或邀请链接加入；房间满员后拒绝第三人。
- 每款游戏都有规则、双方准备、同步开局、完整操控、结果、再来一局和返回房间。
- 支持随机选择游戏和 3/5 场巡回赛；保存本机对战记录。音效可关闭，尊重减少动态效果设置。
- 显示真实连接状态和延迟；短暂断线保留身份，重连拉取权威快照。离线明确提示，不伪造在线对手。
- 可选同设备双人体验用于离线体验/联机服务不可用时的试玩；必须与公网联机状态区分。

## 架构与部署

- 前端：轻量 ESM JavaScript、Vite、DOM/Canvas 2D；20 款使用统一引擎接口，按职责分文件。
- 后端：Node.js + Socket.IO，服务端校验行动、计时、随机序列、隐藏信息、积分与胜负；客户端只发输入。
- 数据：D: 本地 SQLite 保存已结束对局；进行中的房间保存在内存，短线重连恢复；后端重启后不承诺恢复实时对局。
- GitHub 仓库包含完整源码、自动化测试与 GitHub Actions Pages 发布工作流。GitHub Pages 只托管前端。
- 对战服务器在本机 D: 运行，通过加密公网隧道支持远程访问；联调可使用临时地址，长期使用需要固定公网地址。界面支持更换服务器地址并在邀请链接中携带地址。
- 本机必须开机、联网并运行对战服务；不将本机服务描述成脱离电脑的独立云服务器。
- 提供一键启动/停止脚本、健康接口、日志、使用说明；避免在公开仓库写入凭据、隧道 token、个人资料。
- 全部源码、运行时、下载、依赖、缓存、浏览器测试资料、临时文件、数据库、日志都放在 D:/codexAI/duo-play 或已有 D: 工具目录。
