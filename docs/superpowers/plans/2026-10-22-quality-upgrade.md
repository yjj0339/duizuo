# 对座：32 款游戏与统一开始流程 Implementation Plan

> **For agentic workers:** Execute inline with the existing owner. No child agents; preserve the current uncommitted visual and naming work.

**Goal:** 点击游戏即可选择单人或联机，修复贴图和操作问题，复用旧项目优势并增加六款完整游戏。
**Architecture:** 保留纯规则 + 个性化视图 + 稳定 DOM 渲染器、双通道联机与本地 Solo。新增 classics 引擎/视图/AI；模式弹窗独立于选中状态，房间内部选游戏保持双方准备流程。
**Tech Stack:** 既有 Vite、ESM、Canvas/SVG、Node、Socket.IO、SQLite；D 盘运行，无新框架。
**Spec:** 本轮用户要求；docs/CONTRACT.md。

## Global Constraints
- 只在 D 盘运行与下载；使用 duo-play-a 工作副本，保留 b/c 和旧项目。
- 联机规则、时间和分数由服务器决定；单人辅助不带入竞技局。
- 浅色磨砂玻璃；手机从 320px 起；SVG ID 隔离，不拉伸纹理。
- Rapfi 及复用源代码附许可证、来源与可获取源码说明。

## Review Focus
- 大厅游戏卡片/随机入口都弹模式选择；取消不新建房间。
- 重复开始、旧房间恢复、AI 计算中退出不得泄漏 Worker 或覆盖新局。
- 新游戏合法/非法行动、超时、完整结算及 AI 实际出招。
- 旧数独笔记/提示不发送联机作弊操作；旧 AI 棋子编码正确。
- 手机棋盘坐标、SVG 重复 ID、背景尺寸、输入法与焦点。
