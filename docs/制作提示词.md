# 对座 DUIZUO 3.0 · 完整制作提示词

设计、开发并交付一个可通过 GitHub Pages 打开的中文双人对战合集。必须有 32 款真实可玩的不同游戏，适合朋友与情侣，兼顾手机竖屏和电脑。所有项目、运行时、缓存、下载、浏览器档案和测试产物只放 D 盘。已有工作继续迭代，不覆盖个人存档和其他项目。

## 每款游戏

1. **五子棋**（gomoku）：15×15 自由规则，黑方先行。轮流在空位落子，横、竖、斜方向连成至少五子获胜。 操作：点击棋盘落子。
2. **隐藏海战**（fleet）：先随机布阵并锁定舰队，双方准备后轮流攻击。击沉对方全部舰船获胜，未发现的位置保持隐藏。 操作：点击布阵按钮，再点击敌方海域。
3. **点格夺地**（dots）：轮流连接相邻圆点，完成方格的最后一条边就占领它，并再行动一次。领地最多者获胜。 操作：点击圆点之间的边。
4. **翻牌记忆**（memory）：轮流翻开两张牌，相同即可得分并继续翻。全部配对后比较得分，未揭开的牌面保密。 操作：点击两张暗牌。
5. **迷你冰球**（hockey）：拖动你的球拍在己方半场击球，射入对方球门得分，先得 7 分获胜。 操作：拖动球拍或使用方向键。
6. **口袋坦克**（tanks）：控制坦克移动、瞄准和开炮，掩体会阻挡炮弹，击毁对方坦克获胜。 操作：方向键移动、动作键开火，或触屏控制。
7. **泡泡炸弹人**（bomber）：放置倒计时炸弹，十字爆炸可以破坏砖块并触发连锁。最后存活者获胜，同时出局为和棋。 操作：方向键移动，空格/动作键放炸弹。
8. **贪吃蛇竞技场**（snake）：吃食物增长身体，撞到墙壁或蛇身判负。不能直接反向，双方同时碰撞为和棋。 操作：方向键、滑动或触屏方向键。
9. **方块攻防战**（tetris）：双方获得相同顺序的方块，移动、旋转、落下。消行会向对手发送障碍行，封顶判负。 操作：左右移动、上旋转、下加速、空格落下。
10. **弹弓城堡**（slingshot）：轮流选择角度和力度发射，风会影响弹道，命中造成伤害，摧毁对方城堡获胜。 操作：调节角度、力度后发射。
11. **迷宫夺旗**（maze）：在对称可达的迷宫中争夺旗帜，将旗帜带回自己的基地得分，达到目标获胜。 操作：方向键或触屏方向键。
12. **知识擂台**（quiz）：同题限时选择答案，答对得分。每题结束揭晓，全部题目后按总分结算。 操作：点击答案，或按对应数字键。
13. **2048 对决**（g2048）：同种子开局。相同数字相撞合并，一次移动只能合并一次，限时比较分数。 操作：滑动棋盘或方向键。
14. **数独竞速**（sudoku）：双方挑战相同的唯一解数独，行、列和九宫内数字不可重复。先完成或限时正确格数更多者获胜。 操作：选择格子，再点数字键盘。
15. **黑白棋**（reversi）：合法落子必须夹住至少一枚敌方棋子，夹住的棋子翻为己方颜色。无路可下自动跳过，最后数量多者获胜。 操作：点击高亮的合法落点。
16. **石头剪刀布**（rps）：双方暗选，同时揭晓，胜一轮得一分，先得 3 分获胜，平局重赛。 操作：选择石头、剪刀或布。
17. **反应力对决**（reaction）：等待随机信号后点击，抢跑受罚，多轮积分决胜。网络延迟可能影响结果。 操作：看到信号后点击或按空格。
18. **扫雷竞速**（mines）：双方同图竞速，数字代表周围雷数。可插旗，安全格越多得分越高，踩雷受罚。 操作：点击开格，切换插旗或右键。
19. **打字竞速**（typing）：输入相同中文句子，服务器验证正确进度，先正确完成者获胜。支持中文输入法。 操作：点击输入框开始输入。
20. **节奏记忆**（simon）：记住依次亮起的颜色序列并按顺序复现，序列逐轮增长，按正确输入积分。 操作：点击色块或对应数字键。
21. **四子连珠**（connect4）：双方轮流从七列中投入棋子，棋子落到最低空格。先横、竖或斜连成四枚获胜。每回合 45 秒。 操作：点击棋盘任意列，或按 1–7。
22. **井字棋**（tictactoe）：双方轮流落子，先横、竖或斜连成三个标记获胜。棋盘已满则和棋。 操作：点击空格落子。
23. **六边连线**（hex）：六边形棋盘相邻六向连通。蜜桃连接上边与下边，薄荷连接左边与右边。谁先形成完整路径谁赢。 操作：点击六边形空位。
24. **数字华容道**（slide）：相同的可解乱序棋盘。点击与空格相邻的数字移动，把 1–8 按行排好、空格留右下角，先完成获胜。 操作：点击相邻数字，或用方向键移动空格。
25. **拿豆博弈**（nim）：初始三盘分别有 3、5、7 颗豆。每回合只能从一盘拿走至少一颗，拿到最后一颗豆的人获胜。 操作：点豆选择数量，再确认拿走。
26. **星灯棋阵**（lights）：每次点击会翻转自己和上下左右的星灯。相同可解棋盘，先点亮全部 25 盏灯获胜，超时按亮灯数结算。 操作：点击星灯翻转十字范围。
27. **迷你台球**（billiards）：简化八球：首次合法进球分配实色或花色；清空己方球后打黑八。先碰错球、空杆或白球入袋犯规，对手自由放白球。提前进黑八判负。未采用完整比赛的开球与指袋规则。 操作：拖动瞄准、调力度、点击击球；犯规后点球台放白球。
28. **羽毛球对决**（badminton）：横版羽毛球，靠近羽球挥拍，球落对方场内得分。触网、出界或落在己方场内失分。11 分且净胜 2 分获胜，15 分封顶，采用休闲快局。 操作：拖动或左右键移动；1 高远、2 吊球、3 扣杀、↑ 起跳。
29. **乒乓球对决**（tabletennis）：球在己方弹台一次后才能回击，不能连击。触网、出界或二次弹台失分。11 分且净胜 2 分，15 分封顶；每两分换发，10 平后每分换发。发球动作简化。 操作：拖动或上下键移动球拍；空格回击、2 挑高、3 快攻。
30. **微风射箭**（archery）：每人五箭，每轮相同风向。准星加上风偏决定落点，中心 10 环，越偏环数越低。双方落箭后揭晓，五箭总分决定胜负。 操作：拖动靶面或调准星滑块；方向键微调，空格放箭。
31. **点球大战**（penalty）：轮流射门与守门，六个方向同时暗选，同方向扑救成功。各五次，提前锁定胜负即可结算。同分进入最多五轮突然死亡，仍同分则和棋。15 秒未选判失误。 操作：选择六个方向之一，或按 1–6。
32. **跳吃棋**（checkers）：8×8 棋盘，棋子向前斜走一格，有吃必吃，跳过对方棋子并吃掉，可连续跳吃。到达底线升王并结束该次跳吃，王棋可向前或后走与吃。无合法步判负，80 步未吃子和棋。 操作：点棋子，再点高亮落点；方向键选格，Enter 确认。

## 开局流程与视觉

点击任何游戏卡片，先弹出「单人」与「联机」。单人可选挑战 AI、三档难度、先后手或自由练习；联机可直接创建房间或输入六位房间码加入。房间双方准备后同步开局。支持结算、再来一局、换游戏、3/5 场巡回赛。

沿用浅色磨砂玻璃、奶油白、蜜桃粉和薄荷绿，给每款游戏独立且语义清晰的 SVG 插画。棋盘、球台、球拍、角色与特效应有一致的光照和配色，修复纹理重复、裁切、资源引用错误、文字换行和重复比分。界面必须在 320、390 与 1440 像素宽度可用。按钮适合触摸，输入法、键盘焦点、滑块与拖动不能被高频快照重建打断。尊重减少动态效果偏好。

## AI 与旧项目复用

参考 D:/codexAI/aurora-gomoku 的 Rapfi NNUE 和深度搜索，D:/codexAI/mint-1024 的 2048 搜索评估，以及 D:/codexAI/sudoku-atelier 的候选数、逻辑提示与解释。保留许可证和来源说明。五子棋大师应真正调用神经模型并提供可验证的载入状态，失败时诚实显示备用引擎；首次约 11 MB，不能伪称无敌。AI 放在 Worker，仅读取对应玩家的公共视图，不能读取未公开牌面、题目答案、舰船、雷区或对方暗选。

每款游戏都要有贴合玩法的策略：棋类搜索、拿豆异或、华容道路径、星灯线性求解、运动预判、台球几何线路、点球历史观察。不要用一套随机动作冒充 32 款 AI。自由练习可撤销合适的棋盘动作；数独支持手动笔记、自动候选、逻辑解释和明确的填入提示，提示不进入真人对局。单人暂停冻结时间，自动保存并可刷新恢复。

## 联机架构与稳定性

前端使用轻量 JavaScript ESM、Vite、DOM/Canvas；D 盘 Node.js 本地权威服务器通过公网入口连接远程玩家。Socket.IO 为默认通道，独立 HTTPS 长轮询作为兼容通道，共享房间、身份、序号和规则。后台离开或断线冻结对局并保留身份 3 分钟；关闭页面后回来自动找回原座位，双方回来倒计时再继续。保证状态恢复，不能谎称手机系统一定保持后台套接字。服务器定期以 SQLite 保存房间检查点，支持恢复。

客户端仅提交动作；服务器计算物理、时间、得分、胜负并屏蔽秘密。拒绝非法类型、NaN、越界、重复序号和非本人回合。服务器结束后冻结结果。两人使用公平种子，秘密不下发。滑块、击球力度、昵称、房间码等输入均要校验。

先写规则测试并观察失败，再实现。覆盖所有 32 款的合法和非法动作、胜负、超时、隐藏信息、双客户端操作与结算；运行 AI 对局和真实浏览器检查。特别验证 125 秒离开后恢复、通道切换、单人存档、数独笔记和五子棋神经模型。线上 GitHub Pages 与公网服务分别验收；明确同机双浏览器通过代理访问与真实异地手机实测的区别。源代码和静态文件发布到 GitHub，交付地址、D 盘启动方法、完整提示词、验证记录和现有服务器运行限制。用户已经授权直接制作与发布，日常实现不反复请求批准。
