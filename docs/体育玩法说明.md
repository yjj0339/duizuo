# 体育对决规则与简化范围

本合集采用适合触屏的短局玩法。运动场景由 Canvas 绘制，得分和碰撞由服务器计算。

| 游戏 | 对战乐趣与操作 | 简化范围 |
| --- | --- | --- |
| 迷你台球 | 瞄准、力度、球碰球、库边、六袋、球组、犯规自由球、黑八胜负 | 8 分钟；首次合法进球分组；省略指袋、旋转、完整开球细则 |
| 羽毛球 | 移动、起跳、高远球、吊球与扣杀；触网、出界、落地判分 | 横版二维、11 分净胜 2 分、15 分封顶；省略发球区与换边 |
| 乒乓球 | 横向落点、挥拍时机、弹台、快攻与挑高 | 俯视带高度球路；简化发球动作；11 分净胜 2 分、15 分封顶 |
| 微风射箭 | 同风向修正准星，五箭比总环数 | 二维准星加风偏；不模拟真实弓箭器材 |
| 点球大战 | 双方暗选射门/扑救方向，轮流攻守与突然死亡 | 六方向心理博弈；相同方向即扑救，省略门将连续物理 |

规则参考（2026-10-22 查阅的官方资料）：[WPA 八球规则](https://www.wpapool.com/wp-content/uploads/2026/01/2026.01.02-WPA-Rules.pdf)、[BWF 羽毛球规则存档](https://system.bwfbadminton.com/documents/folder_1_81/Regulations/Laws/Part%20II%20Section%201A%20-%20Laws%20of%20Badminton%20-%20May%202017.pdf)、[ITTF Table Tennis 101](https://www.ittf.com/2021/07/22/table-tennis-101/)。这些资料用于确认回合、弹台和犯规概念；合集规则以游戏内短局说明为准，不作为正式赛事规则。
